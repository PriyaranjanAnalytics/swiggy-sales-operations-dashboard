# Swiggy Sales & Operations Dashboard

## Project Overview

This project is an interactive Excel dashboard built to analyze Swiggy sales and operational performance across different cities, states, food categories and time periods.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Dashboard Design

## Key Metrics

* Total Sales
* Total Orders
* Average Order Value (AOV)
* Customer Ratings

## Dashboard Features

* Monthly Sales Analysis
* Daily Sales Analysis
* Weekly Sales Analysis
* State-wise Sales Performance
* Category-wise Revenue Distribution
* City-wise Sales Comparison
* Interactive Slicers and Filters

## Business Insights

* Identified top-performing cities and states.
* Analyzed sales trends across months and weeks.
* Compared category performance between Veg and Non-Veg products.
* Evaluated customer ratings and order behavior.
